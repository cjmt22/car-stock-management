# Car Stock Management System

A graduate-level full-stack project built with ASP.NET Core Web API, PostgreSQL, and vanilla JavaScript.

## Tech Stack
- **Backend:** C# / ASP.NET Core 8 Web API
- **Database:** PostgreSQL with Entity Framework Core
- **Authentication:** JWT with role-based access (Admin, Dealer, Buyer)
- **Frontend:** HTML / CSS / Vanilla JavaScript
- **Docs:** Swagger / OpenAPI

## Features
- User registration and login with JWT authentication
- Role-based access control (Admin, Dealer, Buyer)
- Car listings with full CRUD operations
- Search and filter cars by make, model, price, year
- Test drive booking system
- Admin dashboard with audit logging
